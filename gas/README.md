# LINE 訊息備份工具 — 完整設定說明

> 📌 **重要：所有步驟都要用「你自己的」Google 帳號登入操作**
> 備份的資料夾會建立在你自己的 Google 雲端硬碟，只有你看得到。

---

## 整體流程說明

```
你的 Google 帳號
│
├── 📁 LINE待處理/       ← 你把 LINE 匯出的檔案放到這裡
│                            ↓ 每小時自動處理
└── 📁 LINE備份/
      ├── 📁 王花花/
      │     ├── 📁 2026-06/
      │     │     └── 📄 對話記錄.txt
      │     └── 📁 2026-07/
      │           └── 📄 對話記錄.txt
      └── ...
```

設定只需要做一次，之後每次備份只要 4 個步驟（約 1 分鐘）。

---

## ⚙️ 第一次設定（約 15 分鐘）

---

### 步驟 1：開啟 Google Apps Script

1. 確認你已登入**你自己的** Google 帳號
2. 開啟瀏覽器，前往 👉 **https://script.google.com**
3. 點左上角「**+ 新增專案**」

   > 如果看到「歡迎使用 Apps Script」的畫面，點「**建立新指令碼**」

4. 畫面最上方有個專案名稱「未命名的專案」
5. 點它 → 輸入「**LINE備份工具**」→ 按 **Enter** 確認

---

### 步驟 2：貼上後端程式碼

1. 左側面板點「**Code.gs**」（預設應該已經開啟）
2. 編輯區裡有一些預設文字，**全部選取並刪除**
   - Windows：Ctrl+A → Delete
   - Mac：Cmd+A → Delete
3. 開啟本說明附帶的 **`Code.gs`** 檔案，複製全部內容
4. 貼到編輯區
5. 按 **Ctrl+S**（Windows）或 **Cmd+S**（Mac）儲存
   - 存檔成功後，頁籤標題旁的「Unsaved changes」會消失

---

### 步驟 3：新增 HTML 檔案

> ⚠️ 這個步驟很容易漏掉，請特別注意！

1. 左側面板找到「**Files**」標題
2. 點「**Files**」旁邊的 **「＋」** 號
   ```
   Files   [AZ]  [+]
                  ↑ 點這個
   ```
3. 出現選單，選「**HTML**」
4. 出現「請輸入檔名」輸入框，輸入 **`Index`**（注意：只輸入 Index，不加 .html）
5. 按 **Enter** 確認
6. 左側會多出「**Index.html**」，同時編輯區切換到這個檔案
7. **全部選取並刪除**編輯區的預設內容
8. 開啟附帶的 **`Index.html`** 檔案，複製全部內容
9. 貼到編輯區
10. 按 **Ctrl+S** 儲存

完成後，左側應該看到兩個檔案：
```
📄 Code.gs
📄 Index.html
```

---

### 步驟 4：設定權限範圍（appsscript.json）

> 這個步驟讓工具取得「讀取任何 Drive 檔案」的權限，
> 否則無法讀取你從 LINE 上傳到「LINE待處理」的檔案。

1. 點左側「**⚙️ 齒輪（專案設定）**」
2. 找到「**在編輯器中顯示 appsscript.json 資訊清單檔案**」→ 打開開關
3. 回到編輯器，左側 Files 會多出「**appsscript.json**」，點它
4. **全選刪除**原有內容，貼上以下內容：
   ```json
   {
     "timeZone": "Asia/Taipei",
     "dependencies": {},
     "exceptionLogging": "STACKDRIVER",
     "runtimeVersion": "V8",
     "oauthScopes": [
       "https://www.googleapis.com/auth/drive",
       "https://www.googleapis.com/auth/script.scriptapp"
     ]
   }
   ```
5. **Ctrl+S** 儲存

完成後，左側應該看到三個檔案：
```
📄 Code.gs
📄 Index.html
📄 appsscript.json
```

---

### 步驟 5：建立「LINE待處理」資料夾並啟動自動備份

> 這個步驟會在你的 Google 雲端硬碟建立「LINE待處理」資料夾，
> 並設定每小時自動處理一次。

1. 左側點「**Code.gs**」切換回去
   ```
   Files
     📄 Code.gs      ← 點這個
     📄 Index.html
   ```

2. 畫面上方工具列找到函式選單（在 Debug 按鈕旁邊）：
   ```
   ▶ Run   🐛 Debug   [ 選擇函式 ▼ ]
                       ↑ 點這個下拉選單
   ```

3. 點下拉選單，選「**installTrigger**」

4. 點「**▶ Run**」按鈕

5. **首次執行會跳出授權視窗**，請依以下步驟操作：
   - 點「**審查權限**」
   - 選擇你的 **Google 帳號**
   - 看到「Google 尚未驗證此應用程式」→ 點「**進階**」
   - 點「**前往 LINE備份工具（不安全）**」
     > ⚠️ 這個警告是因為程式是你自己建立的，不是 Google 官方，屬於正常現象，可以放心點。
   - 看到權限清單，會列出類似以下項目，**全部都要允許**：
     ```
     ✅ 查看、編輯、建立及刪除你所有的 Google 雲端硬碟檔案
     ✅ 允許此應用程式在你不在時執行（觸發器需要）
     ```
   - 點「**允許**」

6. 執行完成後，點上方「**Execution log**」查看執行結果

7. 應該看到類似這樣的訊息：
   ```
   ✅ 安裝完成！
   「LINE待處理」資料夾：https://drive.google.com/drive/folders/...
   每小時自動掃描一次...
   ```

   > ⚠️ 如果沒看到這段成功訊息，代表資料夾**尚未建立**，
   > 請回到步驟 4 檢查權限是否正確設定，再重新執行 `installTrigger`。

8. **開啟「LINE待處理」資料夾並在手機上加入書籤**（方便之後每次放檔案不用重新搜尋）：

   **方法一：從電腦加書籤（推薦）**
   - 在 Execution log 裡點擊那個 `https://drive.google.com/...` 連結，在電腦瀏覽器開啟
   - 把這個網址加入瀏覽器書籤

   **方法二：在手機 Google Drive App 加入「快速存取」**
   - 開啟手機的 **Google Drive App**
   - 搜尋「`LINE待處理`」找到這個資料夾
   - 長按資料夾 → 選「**新增至快速存取**」（或「加到已加星號」⭐）
   - 之後在 LINE 分享時，進入 Drive 就能在「已加星號」或「快速存取」直接找到它

---

### 步驟 6：部署管理介面（Web App）

> 這個步驟建立一個網頁，讓你可以查看和管理所有備份。

1. 點右上角「**部署**」→「**新增部署作業**」

2. 點「**類型**」旁邊的齒輪 ⚙️，選「**網頁應用程式**」

3. 填寫設定：

   | 欄位 | 設定值 |
   |------|--------|
   | 說明（選填） | LINE備份工具 |
   | 執行身分 | **我（Me）** |
   | 具有存取權的使用者 | **只有我自己** |

   > 💡 選「Me」表示腳本以你的身份存取 Drive，和觸發器行為一致。
   > 選「只有我自己」表示只有你登入自己的 Google 帳號才能開啟管理介面，更安全。
   > 若未來想讓其他人也能管理，再改為「任何 Google 帳戶的使用者」。

4. 點「**部署**」

5. 再次出現授權要求 → 點「**授權存取**」→ 同樣**全部允許**

6. 複製「**網頁應用程式網址**」，這是你的管理介面連結

   > **之後忘記網址怎麼找？**
   > 「部署」→「**管理部署作業**」→ 在清單裡複製「網頁應用程式網址」

---

### 設定完成！✅

你的 Google 雲端硬碟現在應該多了一個「LINE待處理」資料夾。

## 📱 日常使用方法（每次備份約 1 分鐘）

### 步驟一：在 LINE 匯出聊天記錄

1. 打開 LINE
2. 進入**想備份的對話**
3. 點右上角 **⋮（三個點）**
4. 選「**設定**」
5. 選「**傳送聊天記錄**」

---

### 步驟二：存到「LINE待處理」資料夾

1. 分享選單出現後，找到「**雲端硬碟**」並點它

   > 💡 如果找不到「雲端硬碟」，往下滑或點「更多」

2. Google Drive 開啟後，**導覽到「LINE待處理」資料夾**
   - 可以從「我的雲端硬碟」找到它
   - 或用搜尋功能搜尋「LINE待處理」

3. 點「**儲存**」（或「**選取**」）

完成！

---

### 步驟三：等待自動處理

- 系統每小時自動處理一次
- **最慢等 1 小時**，「LINE備份」資料夾會自動出現整理好的文字檔

#### 不想等？手動立即觸發

1. 前往 👉 https://script.google.com
2. 點開「**LINE備份工具**」專案
3. 左側點「**Code.gs**」
4. 函式選單選「**watchAndProcess**」
   ```
   ▶ Run   🐛 Debug   [ watchAndProcess ▼ ]
   ```
5. 點「**▶ Run**」
6. 點「**Execution log**」查看結果：
   ```
   ✅ 王小明（325 則）   ← 成功
   ❌ ERROR_檔案名稱     ← 失敗（檔名有問題，手動改回正確名稱再試）
   ```

---

### 步驟四：查看備份結果

打開 Google 雲端硬碟，你會看到：

```
📁 我的雲端硬碟
   📁 LINE待處理     ← 你放原始檔案的地方（處理後自動清空）
   📁 LINE備份       ← 整理好的備份在這裡！
      📁 王花花
         📁 2026-06
            📄 對話記錄.txt
```

點開 `.txt` 檔案就能閱讀備份的對話記錄。

開啟你在步驟 6 取得的「**Web App 網址**」：

- 查看所有已備份的對話清單

## ❓ 常見問題

**Q：授權時看到「Google 尚未驗證此應用程式」很可怕，安全嗎？**
A：完全安全。這個程式是你自己建立的，Google 只是還沒驗證。
   程式只存取你自己的 Google Drive，不會把資料傳給任何人。

**Q：「LINE待處理」資料夾裡的原始檔會保留嗎？**
A：處理成功後會自動移到垃圾桶（30 天內可還原）。
   如果處理失敗，檔案名稱會加上「ERROR_」前綴，方便你知道。

**Q：可以重複上傳同一個對話嗎？**
A：可以，工具會自動偵測重複並略過，不會產生重複備份。

**Q：備份超過 1 小時還沒出現怎麼辦？**
A：請確認「LINE待處理」裡有 .txt 檔案，且沒有「ERROR_」前綴。
   或開啟 Web App，用「上傳備份」分頁手動上傳（立即處理）。

**Q：如何停止自動備份？**
A：前往 https://script.google.com → 開啟「LINE備份工具」
   → 函式選單選「removeTrigger」→ 執行。
   已備份的資料不受影響。

**Q：刪除備份後找得回來嗎？**
A：刪除的檔案移至 Google Drive 垃圾桶，**30 天內**可還原。
