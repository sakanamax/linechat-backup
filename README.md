# LINE 訊息備份工具 — 方案說明

> 將 LINE 一對一私訊定期備份到個人 Google 雲端硬碟，操作簡單，完全免費。

---

## 📐 最終採用方案

**LINE 匯出 → Google Drive 自動整理**

使用 Google Apps Script（GAS）建立自動化流程，使用者只需在 LINE 內操作幾個步驟，系統自動整理備份。

---

## 🔄 日常使用流程

```
① LINE 對話 → ⋮ → 設定 → 傳送聊天記錄
        ↓
② 分享到「雲端硬碟」→ 選「LINE待處理」資料夾
        ↓
③ 等待最多 1 小時（系統自動處理）
        ↓
④ Google Drive「LINE備份」資料夾出現整理好的檔案
```

每次備份操作約 **1 分鐘**，其餘完全自動。

---

## 📁 備份結果

資料夾結構可在管理介面自由切換，共有兩種：

**📁 選項 A：依聯絡人分類（預設）**
```
📁 我的雲端硬碟
   📁 LINE待處理          ← 使用者放原始匯出檔案的地方
   📁 LINE備份
      📁 王花花
         📁 2026-06
            📄 對話記錄.txt
         📁 2026-07
            📄 對話記錄.txt
```
> 適合：想快速找到某人所有對話紀錄

**📅 選項 B：依月份分類**
```
📁 我的雲端硬碟
   📁 LINE待處理
   📁 LINE備份
      📁 2026-06
         📄 王花花.txt
         📄 另一位聯絡人.txt
      📁 2026-07
         📄 王花花.txt
```
> 適合：想看某個月份所有人的對話紀錄

每個 `.txt` 檔案包含該月所有對話記錄，含日期、時間、發送者、訊息內容。

## ⚙️ 技術架構

| 元件 | 說明 |
|------|------|
| **Google Apps Script** | 免費的 Google 雲端腳本平台，不需要伺服器 |
| **時間觸發器** | 每小時自動掃描「LINE待處理」資料夾 |
| **DriveApp** | 讀取上傳的檔案、建立整理好的備份結構 |
| **Web App（管理介面）** | 查看備份清單、刪除備份、撤銷授權 |

---

## ✅ 特點

- **完全免費** — 使用 Google 帳號即可，不需任何付費服務
- **完全私密** — 資料存在自己的 Google Drive，不經過任何第三方
- **可切換結構** — 管理介面可隨時切換「依聯絡人」或「依月份」兩種資料夾結構
- **防重複** — 重複上傳同一個對話不會產生重複備份
- **可還原** — 刪除的備份移至垃圾桶，30 天內可還原
- **自動整理** — 按月份資料夾自動分類，多行訊息也正確處理
- **失敗提示** — 處理失敗的檔案加上 `ERROR_` 前綴方便識別

---

## ⚠️ 限制

- **需要手動觸發**：LINE 不提供 API 讓外部程式直接讀取訊息，必須透過 LINE 內建的「傳送聊天記錄」功能手動匯出
- **僅備份文字**：圖片、影片、檔案需另外在 LINE 中手動儲存
- **最多等 1 小時**：觸發器每小時執行一次，若需立即處理可手動在 GAS 執行 `watchAndProcess`
- **Android 格式**：解析器針對 Android 版 LINE 匯出格式（iPhone 格式不同）

## 🚀 部署摘要

1. 用**自己的** Google 帳號前往 [script.google.com](https://script.google.com)
2. 建立新專案，貼上 `Code.gs`、`Index.html`、`appsscript.json`
3. 執行 `installTrigger` → 自動建立「LINE待處理」資料夾並啟動每小時觸發器
4. 部署為 Web App（執行身分：Me；存取：只有我自己）
5. 開啟 Web App 網址 → 捲到最下方「⚙️ 資料夾結構設定」選擇偏好結構並儲存

詳細步驟請參閱 [gas/README.md](gas/README.md)
